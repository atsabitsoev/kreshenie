# Курс подготовки ко крещению — сайт

Сайт из 31 дня по шести темам: **Спасение, Господь, Слово Божие, Молитва, Церковь, Благовестие.**

* **Ученик** открывает свою персональную ссылку, проходит день за днём, отправляет ответы.
* **Наставник** создаёт учеников в Google-таблице, получает для каждого ссылку и видит весь прогресс и все ответы в отдельной панели.
* Всё бесплатно и без сервера: статический сайт на GitHub Pages + Google-таблица как база данных.

---

## Что внутри

```
index.html            страница ученика
mentor.html           панель наставника
assets/
  config.js           ← единственный файл, который вы правите при установке
  course.js           весь текст курса (31 день + приложение)
  style.css           оформление, светлая и тёмная темы
  app.js              логика страницы ученика
  mentor.js           логика панели наставника
  api.js, icons.js    вспомогательные файлы
apps-script/Code.gs   код для Google-таблицы (бэкенд)
data/course.json      тот же курс в JSON — для резервной копии
```

# Установка — 5 шагов, примерно 20 минут

Понадобятся: аккаунт **GitHub** и аккаунт **Google**. Всё делается в браузере.

---

## Шаг 1. Создайте репозиторий на GitHub

1. Зайдите на [github.com](https://github.com) и войдите в аккаунт.
2. Нажмите **+** в правом верхнем углу → **New repository**.
3. Имя репозитория: `kreshenie` (можно любое латиницей).
4. Выберите **Public** — это обязательно для бесплатного GitHub Pages.
5. Нажмите **Create repository**.
6. На открывшейся странице нажмите **uploading an existing file**.
7. Перетащите туда **всё содержимое** этой папки: `index.html`, `mentor.html`, папки `assets`, `data`, `apps-script`, файл `README.md`.
8. Нажмите **Commit changes**.

## Шаг 2. Включите GitHub Pages

1. В репозитории откройте вкладку **Settings** (шестерёнка сверху).
2. Слева выберите **Pages**.
3. В блоке **Build and deployment → Source** выберите **Deploy from a branch**.
4. Branch: **main**, папка: **/ (root)**. Нажмите **Save**.
5. Подождите 1–2 минуты и обновите страницу. Вверху появится адрес вида:

   ```
   https://ВАШ-ЛОГИН.github.io/kreshenie/
   ```

   **Скопируйте его — он понадобится дважды.**

Если открыть этот адрес сейчас, сайт напишет, что ещё не настроен. Это нормально.

## Шаг 3. Создайте Google-таблицу и подключите скрипт

1. Откройте [sheets.new](https://sheets.new) — создастся пустая таблица.
2. Назовите её, например, **«Курс крещения — ученики»**.
3. В меню выберите **Расширения → Apps Script**.
4. Откроется редактор кода. Удалите всё, что там есть (`function myFunction() {}`).
5. Откройте файл `apps-script/Code.gs` из этой папки, скопируйте **весь** его текст и вставьте в редактор.
6. Нажмите значок дискеты (**Сохранить проект**).
7. Вернитесь на вкладку с таблицей и **обновите страницу** (F5).
8. Через несколько секунд в меню появится пункт **📖 Курс**.
9. Выберите **📖 Курс → ① Настроить таблицу**.
   Google попросит разрешение — нажмите **Продолжить**, выберите свой аккаунт,
   на экране «Google не подтвердил это приложение» нажмите **Дополнительные настройки → Перейти к <имя проекта> (небезопасно)**, затем **Разрешить**.
   *Это ваш собственный скрипт в вашей таблице — предупреждение появляется у всех личных скриптов.*
10. Появятся листы: **Ученики, Ответы, Наставники, Настройки**.

## Шаг 4. Опубликуйте скрипт как веб-приложение

1. Снова откройте **Расширения → Apps Script**.
2. Справа вверху нажмите **Развернуть → Новое развёртывание**.
3. Нажмите шестерёнку рядом с «Выберите тип» и выберите **Веб-приложение**.
4. Заполните:
   * **Описание:** `Курс крещения`
   * **Запуск от имени:** **Я** (ваш адрес)
   * **У кого есть доступ:** **Все** ← это обязательно
5. Нажмите **Развернуть** → при необходимости **Предоставить доступ**.
6. Скопируйте **URL веб-приложения**. Он выглядит так:

   ```
   https://script.google.com/macros/s/AKfycb....../exec
   ```

> ⚠️ «У кого есть доступ: Все» означает, что по этому адресу может обратиться любой браузер — иначе ученики не смогут открыть свои ссылки. Данные при этом защищены: без персонального токена сервер ничего не отдаёт. Сама таблица остаётся приватной.

## Шаг 5. Свяжите сайт и таблицу

**5.1. Пропишите адрес скрипта в сайте**

1. В репозитории на GitHub откройте `assets/config.js`.
2. Нажмите карандаш (**Edit this file**).
3. Замените `ВСТАВЬТЕ_СЮДА_АДРЕС_APPS_SCRIPT` на URL из шага 4 — **в кавычках**:

   ```js
   window.CONFIG = {
     API_URL: "https://script.google.com/macros/s/AKfycb....../exec",
     ORG: ""
   };
   ```
4. **Commit changes**. Через минуту сайт обновится.

**5.2. Пропишите адрес сайта в таблице**

1. В таблице: **📖 Курс → ② Указать адрес сайта**.
2. Вставьте адрес из шага 2 (`https://ВАШ-ЛОГИН.github.io/kreshenie/`) и нажмите OK.

Готово. Осталось создать наставника и учеников.

# Как пользоваться

## Добавить наставника

**📖 Курс → 🔑 Добавить наставника** → введите имя.
Скрипт покажет ссылку на панель наставника и запишет её на лист **Наставники**.

Ссылка выглядит так:
```
https://ВАШ-ЛОГИН.github.io/kreshenie/mentor.html?k=m-xxxxxxxx
```
Её нельзя давать ученикам — по ней видны ответы всех.

## Добавить ученика

Два способа — любой на выбор.

**Через меню:** **📖 Курс → ➕ Добавить ученика** → имя → имя наставника.
Скрипт сразу покажет персональную ссылку.

**Прямо в таблице:** откройте лист **Ученики** и просто впишите имя в столбец **А**.
Токен и ссылка появятся автоматически через секунду.

Ссылка ученика выглядит так:
```
https://ВАШ-ЛОГИН.github.io/kreshenie/?s=s-xxxxxxxx
```
Отправьте её ученику в мессенджере. Это его вход — ни пароля, ни регистрации не нужно.

## Что видит ученик

* Дни открываются по порядку: следующий доступен после отправки предыдущего.
* Ответы сохраняются автоматически, пока он печатает — и на его устройстве, и в таблице. Можно закрыть вкладку и вернуться хоть с телефона, хоть с компьютера.
* После отправки день становится доступен только для чтения.
* Слева (на телефоне — по кнопке меню) видно всё содержание курса и пройденные дни.
* Есть тёмная тема и раздел «Приложение» с материалами для благовестия.

## Что видит наставник

* Список учеников: прогресс, дата последней активности, полоса из 31 дня.
* Клик по ученику — карточка: дни по модулям, кнопка «Скопировать ссылку», «Открыть как ученик».
* Клик по любому пройденному дню — все его ответы.
* «Все ответы подряд» — весь путь ученика одним списком; кнопка «Печать» сохраняет его в PDF (удобно перед встречей).
* Кнопка обновления в шапке подтягивает свежие данные.

## Что видно в таблице

* **Ученики** — имя, наставник, токен, персональная ссылка, прогресс, последняя активность, столбец для заметок.
* **Ответы** — по строке на каждый отправленный день. Столбец **«Ответы»** содержит читаемый текст: вопрос и под ним ответ ученика. Можно фильтровать, искать, выгружать.
* **Черновики** — скрытый служебный лист, трогать не нужно.

Если числа в столбце «Прогресс» разошлись с реальностью — **📖 Курс → 🔄 Пересчитать прогресс**.

# Частые вопросы

**Ученик открыл ссылку — пишет «Ссылка не найдена».**
Проверьте, что в листе «Ученики» у него заполнен столбец **Токен**, и что ссылка скопирована целиком, вместе с `?s=...`.

**Сайт пишет «Сайт ещё не настроен».**
Не выполнен шаг 5.1 — в `assets/config.js` остался текст-заглушка.

**Ответы не сохраняются, «Нет связи».**
Скорее всего, в шаге 4 в поле «У кого есть доступ» стоит не «Все». Откройте **Развернуть → Управление развёртываниями**, нажмите карандаш, исправьте и нажмите **Развернуть**.

**Я изменил Code.gs — изменения не применились.**
Apps Script работает по версиям. После правки: **Развернуть → Управление развёртываниями → карандаш → Версия: Новая версия → Развернуть**. Адрес `/exec` при этом не меняется.

**Можно ли дать ученику начать заново?**
Удалите в листе **Ответы** все его строки (по токену) и выполните **🔄 Пересчитать прогресс**. Ссылка останется прежней.

**Как заблокировать ученику доступ?**
Очистите его токен в листе «Ученики» — старая ссылка перестанет работать.

**Сколько это выдержит?**
Лимиты Google для личного аккаунта — десятки тысяч обращений в сутки. Для группы в сотню учеников запас многократный.

**Насколько это безопасно?**
Токен — 18 случайных символов, подобрать его перебором нереально. Ссылка ученика открывает только его собственные ответы; ссылка наставника — только чтение. Сама таблица видна лишь тем, кому вы дали к ней доступ в Google. Личные данные в курсе не собираются — только имя, которое вписали вы.

# Как менять содержание курса

Весь текст курса лежит в **`assets/course.js`** — одна строка вида `window.COURSE = {...}`. Это JSON: модули → дни → блоки.

Структура одного дня:

```js
{
  "id": "1-1",                       // уникальный, менять нельзя у уже пройденных дней
  "title": "Нам прощены грехи",
  "intro": ["абзац", "абзац"],       // допускается <em>, <b>
  "verse": { "text": "…", "ref": "1 Ин. 2:12" },
  "read":  { "ref": "1 Ин. 2:12–14", "label": "Прочтите весь отрывок…" },
  "blocks": [ … ],                   // поля для ответов и пояснения
  "notes":  [ { "term": "Прощать", "text": "…", "src": "Словарь Даля" } ]
}
```

Типы блоков:

| Тип | Что это |
|---|---|
| `keywords` | пары «ключевое слово + определение» (`count` — сколько пар) |
| `textarea` | одно поле для свободного ответа (`rows` — высота) |
| `fields` | несколько подпунктов а), б), в) |
| `stepform` | шаг метода (Шаг 1–4) с полем внутри |
| `rule`, `step` | пояснительный блок без полей |
| `answerkey` | «ответы на вчерашнее задание» (зелёный блок) |
| `callout`, `checklist`, `numbered`, `criteria`, `truths`, `table3` | справочные блоки |

Правки удобнее вносить в `data/course.json` (он отформатирован), а затем перенести в `assets/course.js` — это то же самое, обёрнутое в `window.COURSE = …;`.

**Важно:** ответы учеников привязаны к `id` дня и `id` блока. Менять текст можно свободно; менять идентификаторы у дней, которые уже кто-то прошёл, — нет.

# Свой домен (необязательно)

В **Settings → Pages → Custom domain** впишите свой домен и добавьте у регистратора CNAME на `ВАШ-ЛОГИН.github.io`. После этого не забудьте обновить адрес сайта в таблице (**📖 Курс → ② Указать адрес сайта**) — ссылки перевыпустятся автоматически, старые токены останутся прежними.
